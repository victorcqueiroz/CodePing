# Marca CodePing

Símbolo original de código com um ponto de notificação. Azul `#125FB5`, verde `#288568`, texto `#192638`. A marca acompanha o tema Claro existente.

- `codeping-logo.svg`: marca horizontal editável, fundo transparente.
- `codeping-mark.svg`: símbolo vetorial isolado.
- `CodePingMark.xaml`: desenho nativo consumido pelo painel e pelo aviso WPF.
- `codeping-logo.png`: marca horizontal transparente.
- `codeping-preview.png`: marca sobre branco, para apresentação.
- `codeping-mark.png`: símbolo transparente em 512 px.
- `codeping.ico`: ícone do Windows em 16, 20, 24, 32, 40, 48, 64, 128 e 256 px.

Para reproduzir os PNGs e o ICO a partir do desenho XAML no Windows: `scripts/brand-assets.ps1`. Não requer rede, fontes externas ou pacotes adicionais. A assinatura usa Segoe UI com alternativa Arial/sans-serif no SVG.
